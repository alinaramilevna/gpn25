# GPN25 — Оптимизация энергопотребления (репозиторий команды)

**Кратко:** репозиторий содержит решение кейса по оптимизации энергопотребления на Приобском месторождении (Кейс №25). В проекте:
- таблицы и первичный анализ (задание 1);
- модель расчёта энергозатрат и экономии (задание 2, 4) — Python (FastAPI);
- веб-интерфейс (задание 3) — Next.js frontend;
- презентация и вспомогательные материалы для защиты.

## Короткое описание реализованных задач

### Задание 1 — анализ и подготовка данных
- Файлы: `1/` (Excel).
- Что сделано: подготовлен исходный набор данных, базовый анализ (распределения, проверки пропусков), формализованы входные параметры для модели (начальные энергозатраты, временной горизонт, коэффициенты снижения/роста цены).
- Где смотреть: `1/` — Excel-файл с расчётами и промежуточными таблицами.

### Задание 2 — математическая модель энергозатрат и экономического эффекта
- Файлы: `energy-calc-python/core/calculate_savings.py`
- Что реализовано: модель экспоненциального снижения энергозатрат и учёта изменения цены на энергию.  
  Функция:
  ```python
  get_savings(start_energy, time, energy_low_coeff, start_price, price_up_coeff)
  ```
  возвращает суммарную экономию и итоговые параметры.

Примечание: модель параметризуема — можно менять `start_energy`, `time`, `energy_low_coeff`, `start_price`, `price_up_coeff`.

### Задание 3 — веб-интерфейс / дашборд
- Файлы: `energy-calc-frontend/app/page.tsx` и компоненты.
- Что реализовано: страница с формой для ввода параметров (начальные энергозатраты, горизонт, коэффициенты) и кнопкой обновления.

Два ключевых запроса:
```
GET /api/savings?start_energy=...&time=...&energy_low_coeff=...&start_price=...&price_up_coeff=...
GET /api/plot?start_energy=...&time=...&energy_low_coeff=...
```

По умолчанию в коде фронтенда указан адрес `http://176.108.240.204/api/...` — при локальном запуске заменить на `http://localhost:<порт>`.

### Задание 4 — интеграция и визуализация результатов
- Файлы: `energy-calc-python/core/get_plots.py`, frontend визуализация.
- Что реализовано: генерация PNG-графиков динамики энергопотребления (`get_plot` сохраняет картинку в `tmp/...png`), отображение графика на фронтенде.
- Опции для улучшения: добавить кэширование, вернуть график как base64, добавить экспорт отчётов (PDF/Excel).

## Как запустить проект локально

### Склонируйте репозиторий:
```bash
git clone https://github.com/alinaramilevna/gpn25.git
cd gpn25/GPN
```

### Бэкенд (Python, FastAPI):
```bash
python3 -m venv venv
source venv/bin/activate       # или venv\Scripts\activate на Windows
pip install -r requirements.txt
cd energy-calc-python
python app.py
```
API будет доступен локально (по умолчанию на 8000 порту, если запускать через `uvicorn app:app --reload --port 8000`).

Эндпойнты:
- `/api/savings`
- `/api/plot`

### Фронтенд (Next.js):
```bash
cd ../energy-calc-frontend
npm install
npm run dev
```
Открыть [http://localhost:3000](http://localhost:3000). При необходимости поправить URL API во фронтенде.
